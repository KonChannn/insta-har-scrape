Instagram HAR Analyzer
🔒 File HAR berisi cookie & sesi login Instagram. Jangan bagikan file .har ke siapa pun. Tool ini berjalan 100% lokal di browser: hanya membaca response body, mengabaikan header/cookie/token, dan tidak menyimpan file mentah.

Cara mengambil file .har (hasil paling lengkap)

  1. Buka Chrome/Edge, login Instagram, lalu buka DevTools (F12 / Cmd+Opt+I) → tab Network. Centang Preserve log, ketik graphql di kolom filter.
  2. Buka instagram.com/NAMAAKUN/ (halaman profil) → refresh halaman supaya query profil (followers, bio) ikut terekam.
  3. Scroll grid post sampai sejauh periode yang mau dianalisa (mis. 3 bulan / 50–100 post).
  4. Buka tab Reels (/NAMAAKUN/reels/) dan scroll juga — di sinilah jumlah views/plays biasanya muncul.
  5. Untuk analisa komentar & jam aktif audience: buka 5–10 post (terutama yang ramai), scroll kolom komentar & klik "lihat komentar lainnya".
  6. Akun sendiri/klien dengan akses: buka Professional Dashboard / Insights post dan akun untuk data reach, saves, shares, audience.
  7. Klik kanan daftar request → Save all as HAR with content (atau ikon ⬇ "Export HAR"). Upload file itu ke sini.
